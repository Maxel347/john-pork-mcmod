# maxmodcool — John Pork Minecraft Mod

A Minecraft Forge mod for version **1.20.1** that adds new custom entities to the game, including the fearsome **Rhino** and the legendary **Porkus**.

---

## Installation

1. Make sure you have **Minecraft 1.20.1** installed
2. Download and install **[Forge 1.20.1](https://files.minecraftforge.net/)** (recommended version: 47.x)
3. Download the latest `.jar` file from the [Releases](../../releases) tab
4. Place the `.jar` file into your Minecraft `mods` folder:
   - Windows: `%appdata%\.minecraft\mods\`
   - Linux/Mac: `~/.minecraft/mods/`
5. Launch Minecraft with the Forge profile and enjoy!

---

## Entities

### Rhino
- A large and powerful creature roaming the overworld
- 40 HP (20 hearts)
- Deals massive **200 attack damage**
- Extra armor for protection
- Can breed using **Cooked Beef**

### Porkus
- A hostile humanoid monster
- Actively hunts down players
- Custom animations including attack arm raise
- Roams the world looking for its next victim

---

## Spawning

You can spawn the entities using the following commands:

```
/summon examplemod:rhino
/summon examplemod:porkus
```

Or find a **Porkus Spawn Egg** in the creative inventory.
